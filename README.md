# Aumentado

Landing minimal con [Next.js](https://nextjs.org), TypeScript, Tailwind CSS y una escena 3D con React Three Fiber.

## Empezar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

## Scripts

- `npm run dev` — servidor de desarrollo
- `npm run build` — build de producción
- `npm run start` — servidor de producción
- `npm run lint` — ESLint
